negaflow SANE Scanner

This installer prepares the complete SANE scanner connection for negaflow.

  1. Installs the official Homebrew package when Homebrew is not already present.
  2. Installs sane-backends with Homebrew for the logged-in user.
  3. Installs the negaflow SANE scanner plug-in in the logged-in user's Application Support folder.

An internet connection, macOS 14 or later, and Xcode Command Line Tools or Xcode are required.
