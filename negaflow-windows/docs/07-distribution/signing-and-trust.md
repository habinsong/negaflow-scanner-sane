# Windows 서명과 신뢰

기준일: 2026-08-25

현재 x64 배포물은 NSIS 설치 파일입니다. 코드 서명 인증서는 아직 연결하지 않았습니다. 따라서 설치 파일과 플러그인 실행 파일의 Authenticode 신뢰를 주장하지 않습니다.

플러그인은 설치 뒤 Negaflow 본체에서 한 번 신뢰 승인을 받아야 합니다. 이후에는 승인 당시와 파일 해시가 같은 경우에만 실행합니다. 이 검사는 Authenticode 서명을 대신하지 않습니다.

릴리스 전에 확인할 항목:

- 설치 파일과 플러그인 실행 파일의 서명
- 설치 파일의 SHA-256 파일
- GPL license·notice·대응 소스 payload
- 새 설치, 업데이트, 제거 뒤 플러그인 발견과 `detect`
