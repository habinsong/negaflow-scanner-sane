## 0. 원칙

**가장 싸게 프로젝트를 죽일 수 있는 것을 먼저 한다.**

이 이식에는 프로젝트 전체를 무의미하게 만들 수 있는 미확인 항목이 셋 있다.

```text
W0-1  Windows에서 scanimage가 바이트 정확한 TIFF를 낼 수 있는가
W0-2  Windows에서 SANE가 실제 대상 스캐너를 열 수 있는가
W0-3  코드 서명 인증서를 확보할 수 있는가 (호스트가 요구한다면)
```

셋 다 장비 한 대와 며칠이면 답이 나온다. **구현을 시작하기 전에 답을 얻는다.**

## M0 — 실행 가능성 (gate)

**목표**: 이 프로젝트가 가능한지 확인한다.

| 작업 | 산출 |
|---|---|
| MSYS2 sane 패키지 설치 | 동작하는 `scanimage.exe` |
| S-2: binary stdout 검증 | 결정: A 경로 진행/폐기 |
| S-1: 실제 장치 열기 | 결정: A 경로 진행/폐기 |
| S-4: 장치명 형식 | 2장 코드에 반영할 사실 |
| S-6 / E-3: 로케일 | 반올림 감지 가능 여부 |
| E-2: `SANE_CONFIG_DIR` 경로 처리 | 재빌드 필요 여부 |
| D-1: 서명 인증서 | 결정: 배포 가능 여부 |
| 호스트가 서명을 요구하는지 확인 | negaflow 팀과 협의 |

**통과 조건**

- 대상 스캐너 1대 이상에서 `scanimage -f`, `-A`, 전체 스캔이 성공한다
- 결과 TIFF가 유효하다
- 서명 경로가 있거나, 없어도 진행 가능함을 확인했다

**실패 시**: A 경로를 폐기하고 M0을 B(WSL2) 경로로 반복한다.
둘 다 실패하면 프로젝트를 중단하고 그 사실을 문서화한다.

**예상 기간**: 1~2주 (장비 확보 시간 제외)

## 병행 가능성

```text
M1 ─┬─ M2 ─┬─ M5 ─┬─ M7 ─ M8 ─ M9
    │       │      │
    │  M3 ──┤      │
    │       │      │
    │  M4 ──┘      │
```

## 언제 중단할 것인가

프로젝트를 접는 것이 옳은 조건을 미리 정한다.

```text
M0에서 A와 B 경로가 모두 실패
    → SANE 기반 Windows 지원이 불가능하다. 중단하고
      TWAIN/WIA 어댑터를 권고한다.

N-1 실패 + macOS 변경이 승인되지 않음
    → 이미지 결과가 플랫폼에 따라 다르다. 불변식 I-4 위반.
      다중 노출 기능을 Windows에서 비활성화하거나 중단한다.

서명 불가 + 호스트가 서명을 요구
    → 배포할 수 없다. 중단하거나 호스트 정책 변경을 요청한다.

DC-2에서 대상 장치 대부분이 되돌리기 불가
    → 사용자에게 되돌릴 수 없는 변경을 시킬 수 없다.
      WSL2 경로로 전환하거나 중단한다.
```

**중단이 실패가 아니다.** 답을 얻지 못한 채 오래 진행하는 것이 실패다.
